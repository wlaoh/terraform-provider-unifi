# Icmp Firewall Policy (Resource)

Manage a user-defined IPv4 ICMP Echo Request firewall policy using an Integration API key. Traffic must originate on one of the selected networks and target one of the listed IPv4 addresses within the configured zone pair. Use Integration API UUIDs for all identifiers. Each policy must have a single Terraform owner. To adopt an existing policy, release any legacy `unifi_firewall_policy` state binding without destroying the policy, then import here. Manage evaluation order separately with `unifi_firewall_policy_ordering`.

## Example Usage

```terraform
# Use Integration API UUIDs from this site. Replace these example values.
resource "unifi_icmp_firewall_policy" "gateway_ping" {
  site_id                    = "11111111-1111-4111-8111-111111111111"
  source_zone_id             = "22222222-2222-4222-8222-222222222222"
  destination_zone_id        = "33333333-3333-4333-8333-333333333333"
  source_network_ids         = ["44444444-4444-4444-8444-444444444444"]
  destination_ipv4_addresses = ["192.0.2.1"]
  name                       = "Allow ping to own gateway"
  action                     = "ALLOW"
  enabled                    = true
}
```

## Schema

### Required

- `action` (String) Action for matching echo requests. Select `ALLOW`, `BLOCK`, or `REJECT`.
- `destination_ipv4_addresses` (Set of String) Individual destination IPv4 addresses. Supply the gateway address to match ping requests to that gateway.
- `destination_zone_id` (String) Integration API UUID of the destination zone. Select the gateway zone for traffic destined for the gateway itself.
- `enabled` (Boolean) Whether the policy is enabled.
- `name` (String) Policy name.
- `site_id` (String) Integration API site UUID.
- `source_network_ids` (Set of String) Integration API UUIDs of the source networks. Supply at least one.
- `source_zone_id` (String) Integration API UUID of the source zone.

### Optional

- `allow_return_traffic` (Boolean) For an ALLOW policy, create a derived policy to allow return traffic. Defaults to false.
- `description` (String) Policy description.
- `logging_enabled` (Boolean) Log traffic matching this policy. Defaults to false.

### Read-Only

- `id` (String) Integration API policy UUID. Use this ID when managing zone-pair ordering.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell

terraform import unifi_icmp_firewall_policy.gateway_ping 11111111-1111-4111-8111-111111111111/55555555-5555-4555-8555-555555555555
```
